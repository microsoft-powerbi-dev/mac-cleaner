# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

MacCleaner: a native SwiftUI macOS app (macOS 14+, arm64 only, Xcode 16+) with four features — Junk Cleaner, Uninstaller, Disk Analyzer, System Monitor (main window + menu-bar extra). No network access, no telemetry, no third-party dependencies. App Sandbox is deliberately **off** (it must read `~/Library` and `/Applications`).

## Build & test

The Xcode project is generated by XcodeGen from `project.yml` (repo root) and is gitignored, as are `MacCleaner/App/Info.plist` and `MacCleaner.entitlements`. Edit `project.yml`, never the generated files. Re-run `xcodegen` after adding/removing source files.

```bash
brew install xcodegen
xcodegen                                   # generates MacCleaner.xcodeproj
xcodebuild -project MacCleaner.xcodeproj -scheme MacCleaner build
xcodebuild -project MacCleaner.xcodeproj -scheme MacCleaner test
# single test class / method:
xcodebuild -project MacCleaner.xcodeproj -scheme MacCleaner test -only-testing:MacCleanerTests/SafetyGuardTests
xcodebuild -project MacCleaner.xcodeproj -scheme MacCleaner test -only-testing:MacCleanerTests/SafetyGuardTests/<testMethod>
```

Builds are ad-hoc signed (`CODE_SIGN_IDENTITY: "-"`). Many scan targets need Full Disk Access; after a rebuild macOS may drop the grant (remove and re-add the app in System Settings → Privacy & Security → Full Disk Access).

## Architecture

Feature folders (`Cleaner/`, `Uninstaller/`, `Analyzer/`, `Monitor/`) each pair a pure scanning type with a view file. The view file also holds the feature's `@MainActor @Observable final class …Model`; heavy file-system work is pushed off the main actor via `Task.detached` / task groups and the results are `Sendable` value types.

**Deletion pipeline — the central safety invariant.** All removal goes through `Core/Trasher.remove(_:mode:)`, which calls `SafetyGuard.validate(_:)` on every URL before touching it. Never call `FileManager.removeItem`/`trashItem` directly from feature code.
- `SafetyGuard.standard` allows only paths strictly *inside* `$HOME` or `/Applications`; blocks protected subtrees (`/System`, `/Library`, iCloud/CloudStorage, Keychains, Mail, Messages, Photos library, …) and protected exact folders (the roots themselves like `~/Library/Caches` — you may delete their children, not the folder). Comparisons are lowercase/case-insensitive. `validate` additionally rejects symlinks in the parent chain and the app's own bundle. `checkPolicy` is the pure-string half used by tests.
- Default mode is move-to-Trash. `.permanent` is reserved for the "Empty Trash" category only (enforced by `CleanupCatalogTests.testOnlyTrashIsPermanent`).

**Junk Cleaner.** `CleanupCatalog.all` is the data-driven list of `CleanupCategory`s. Each `Target` has `contentsOnly` (scan children vs. the folder itself) and `excluding` (child names handled by another category — e.g. `~/Library/Caches` excludes Homebrew/pip/browser caches so they aren't double-counted). Modes: `.trash`, `.permanent`, `.listOnly` (size shown, not cleanable). `CleanerScanner` scans categories concurrently and preserves catalog order. To add a category, add an entry to `CleanupCatalog.all`; `CleanupCatalogTests` verifies unique IDs and that every cleanable target passes `SafetyGuard` — if it fails, fix the target rather than loosening the guard.

**Uninstaller.** `AppInventory` lists apps; `LeftoverFinder` scans fixed `~/Library` subfolders and matches entries by bundle ID (high confidence, pre-checked) or app name (low confidence, starts unchecked). `com.apple.*` bundles are never matched. `libraryRoot` is injectable for tests.

**Disk Analyzer.** `DiskScanner` builds a size tree with a `CancelFlag` for cancellation; also produces Large Files (>100 MB) and Old Files (>10 MB, not opened in a year).

**Monitor.** `SystemStats` reads CPU/memory/disk/battery/thermal via Mach (`host_statistics`) and IOKit. `SystemMonitor.shared` is a singleton started in `MacCleanerApp.init`, refreshed by a 2s timer, and shared between the main window and `MenuBarExtra`.

`Core/FileSizer` computes on-disk sizes; `Core/Permissions` detects Full Disk Access heuristically by probing TCC-protected folders; `Shared/Formatting` (`Format`) holds number/byte formatters.
